# 任务收尾 CLI

## Goal
一个 CLI、check/sync 两个动作、默认零 Agent。以 CM → CapMesh 的已确认状态引用证明跨仓闭环，避免每仓一套动作、后台服务和语义推断。

## Scope
CM 持有标准库实现；一个本机 JSON 显式指定来源段落与接收文件。来源必须提交；目标只允许新文档或已带校验的同步区域。正常输出一行。Git 提交/推送仍由当前收尾者负责，不由脚本批量接管脏仓。

## Acceptance
- [x] check 无写入；sync 幂等、区域外字节不变、已检测手改/并发/路径异常不覆盖（普通编辑器并发边界见用法）。
- [x] 来源 Git 版本与链接可追溯；无关提交不引发重复更新。
- [x] CM → CapMesh 真实运行，消除接收方重复维护当前验收状态。
- [ ] 必要测试、安装与提交推送；已有遗留保留并交接。

## Boundaries
不操作服务器/飞书，不调用模型/Agent，不自动安装 cron/hook，不改变 SpecMesh 公共规范。同步不等于部署或产品验收。阶段为首条声明式引用链，未宣称五仓全接通。
