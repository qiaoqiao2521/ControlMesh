# Cron安全规范任务

## Goal / Scope
用户批准将失败循环防护写入CM仓库，只改文档和模板；不修改生产调度、安全配置、历史数据。后续用户明确授权本次文档commit/push至独立分支，保持工作区干净，不合并main。
Paperclip拥有生命周期，CM仅提供前置准入和验收契约，不重建调度器。

## Steps
- [x] 核实官方仓库、干净基线与Paperclip所有权。
- [x] 阅读现有适配入口、迁移证据及测试入口。
- [x] 编写规范、审查模板并接入当前文档索引和历史cron入口。
- [x] 静态检查链接、格式、模板预算与必需验收项，独立复读diff。

## Success
永久缺源不启模型/补丁、临时错误最多3重试、状态持久且磁盘有界，全部具有可执行验收标准。
文档验证与未来运行实施/部署验证明确分开。
